# Uniac

Uniac is a cloud platform for AI agents to build and run web apps, websites, agents, databases and background workers. A coding agent such as Claude Code, Cursor or Codex describes the application and the cloud resources it needs in one file and deploys every service with one command, and the dashboard shows what is running and what it costs. Pricing is usage-based, on a $5 monthly subscription.
